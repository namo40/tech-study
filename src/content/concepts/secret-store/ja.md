シーンの 3 つめのステップは、資格情報がどこかに複製された値であることをやめ、何かが所有する記録になる場面です。ポッドがデプロイされ、ストアからファイルがマウントされて届き、そのあと環境変数には決して用意できない 3 つのことが起こります。これをどのワークロードが読んでよいかを言うリストが現れ、リストに載っていないワークロードの手が `deny` に着地し、ストアのカウンターがひとつ上がります。あの deny は後から付け足したエラー処理ではありません。それこそが機能であり、ストアが誰でも読めるディレクトリと違う唯一の理由です。

バージョンから始めるのがよいでしょう。残りはすべてそこから導かれるからです。ストアは現在の値とそれ以前の値を、それぞれ固有の識別子のもとに保持します。つまりローテーションは、複製が行き着いたすべての場所をそろえて直す作業ではなく、きちんと定義された操作になります。利用側が追いつくあいだ 2 つのバージョンが同時に有効でいられますし、古いものを破棄せずに無効化でき、インシデントのときには「そのワークロードはどのバージョンを握っていたのか」に推測ではなく答えが出ます。最後の性質は聞こえるより値打ちがあります。漏洩の疑いを、際限のない問いから範囲のある問いに変えてくれるのがそれです。

次はリストです。クラスターのすべてのワークロードが読めるストアは、インフラだけが増えた焼き込まれたシークレットです。プロセスひとつが侵害されたときの影響範囲がまた全体に戻ってしまうのに、そこへ行き着くためにボールトの費用を払ったことになります。ストアの値打ちは、アクセスがシークレットごとに書き下ろされた判断だという点にあります。この項目はこれらのワークロードが読めて、それ以外の何も読めない、という判断です。Kubernetes ならシークレットオブジェクトに掛かる RBAC、クラウドのボールトならボールトや個々の項目へのロール割り当て、CSI ドライバーならマウント時に提示されるポッド自身の ID です。3 つの形はどれも同じことを言いますし、どれもレビュー中の人が読めます。そこが肝心です。

次は監査です。すべての読み取りがひとつの扉を通るので、ストアは誰がいつその扉を開けたかを言えます。これはコンプライアンスの記入欄ではありません。「過去 2 年のどこかの時点で、クラスターにアクセスできる何かがその資格情報を読んだかもしれない」と、時刻の付いたサービス ID 3 つのリストとの差です。漏洩への答えがローテーションであるとき、そのローテーションがどこまで届くべきかを教えてくれるのが監査の記録です。

ストアからの配達には 2 つの形があり、シーンは 1 つめを描いています。マウントされたファイル、つまり投影されたシークレットボリュームや外部ボールトから引いてくる CSI ドライバーは、そのポッドだけが見える `tmpfs` のパスに値を置き、ストアが変わればその場で更新します。ファイルは誰も継承せず、クラッシュダンプにも含まれず、診断ページも出力しません。2 つめの形は起動時の取得です。アプリケーションが自分の ID でストアに値を求め、メモリーに持ち、どこにも書きません。こちらはクライアントライブラリと起動時の依存という費用が掛かりますが、いちばん固い保持を手に入れます。シークレットが、それを必要とするプロセスの中だけに存在するようになるのです。

きちんと押さえるべきなのは、ストアが信頼する ID です。連鎖全体が地面に着くのがそこだからです。ワークロードが資格情報でボールトに認証するなら、問題を解いたのではなく 1 つ先に移しただけで、こんどはその新しい資格情報が注入され、ローテーションされ、範囲を絞られる番になります。抜け道は、プラットフォームにワークロードを保証させることです。フェデレーションされたトークン、マネージド ID、ボールトが信頼するよう伝えられたサービスアカウントなどであれば、連鎖の最後のシークレットはシークレットでなくなります。シークレット注入とワークロード ID が出会うのがこの地点です。ストアは、存在しなければならない資格情報を配達する方法であり、フェデレーションは、ストアまで届く資格情報が存在しなくなる方法です。

ストアを正直に保つ習慣が 2 つあります。すべてを詰め込んだ共有項目ひとつではなく、ワークロードごとに自分の項目を与えてください。共有項目は範囲を絞ることも、利用側ひとつのためにローテーションすることもできません。そして、アプリケーションが知っていることを名前の水準まで減らしてください。キーひとつ、URI ひとつ、マウントパスひとつで足ります。アプリケーションが項目の名前を呼べても、ストアを一覧できないのであれば、そのアプリケーションのバグは、すべての資格情報についてのバグではなく、資格情報ひとつについてのバグにとどまります。

キャプションは 1 行で言います。一箇所で管理され、リストで絞られます。このページの残りは、その 2 つの節が何を支払い、何を買うのかという話です。
